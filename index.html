Configuration (1 fois)

Il manque la config Firebase pour synchroniser les joueurs.

  1. Va sur console.firebase.google.com → Ajouter un projet (gratuit).
  2. Menu Build → Realtime Database → Créer (région Belgique ou Europe).
  3. Onglet Règles, colle ceci puis Publier : 
    { "rules": { "games": { ".read": true, ".write": true } } }
  4. Roue ⚙ → Paramètres du projet → Ajouter une appli Web → copie l'objet firebaseConfig.
  5. Colle-le dans ce fichier à la ligne FIREBASE_CONFIG, puis héberge le fichier (Netlify Drop / GitHub Pages) : le GPS exige du HTTPS.
